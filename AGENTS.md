# AGENTS.md — start here

This repo translates English Markdown into bilingual documents. The
mechanical steps are code (five CLI subcommands); the arbitration step is
you. Read only the doc that matches your job:

- **Using this project to translate?** Read `docs/USING.md`. It has the
  full workflow, the command contracts (JSON shapes, exit codes), the
  hard rules, and the translation standard.
- **Changing the code?** Read `docs/HACKING.md`. It has the architecture,
  module roles, invariants you must not break, and test commands.

Human-facing overview (what & why, not contracts): `README.md`.
